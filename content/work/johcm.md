## Problem
> Financial data has to be right before it can be pretty.

I designed the wireframes, concept, design system and UI for a new fund explorer for J O Hambro Capital Management, a global investment boutique with offices across Europe, Asia and the US.

Fund pages carry a lot of weight: performance, charts, documents, disclosures, for institutional and wholesale clients who notice when a number looks off. The explorer also had to work across regions and audiences, and plug into sales and marketing tools.

## Approach
**Tokens and variables first.** Colour, type and spacing ran on tokens and variables, so the same components held up across desktop, tablet and mobile.

**Modular explorer.** Filters, fund cards and data modules all came from one component library, so new views could be assembled rather than redesigned.

**Progressive disclosure.** A "view more" pattern reveals complex fund detail on demand, so the first screen stays readable.

## System
**Theme flexibility.** Core components adapt colour, type and structure for different themes without breaking accessibility. One component library behind every explorer view, on every breakpoint.

## Outcome
The system was built on design tokens, variables and reusable brand components, so future projects could start from the same foundation instead of from scratch.
